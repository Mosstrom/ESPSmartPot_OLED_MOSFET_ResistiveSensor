# ESPSmartPot
Умный горшок (УГ) для автополива домашних растений в зависимости от влажности почвы

**Элементная база:**

-	Модуль ESP8266 с двухцветным дисплеем OLED 0,96” 
-	Модуль MOSFET ключа XY-MOS на двух транзисторах GAD107
-	Помпа 5В
-	Резистивный датчик влажности почвы
-	Поплавковый датчик уровня воды в баке (замкнутый при отсутствии воды)
-	Кнопка без фиксации, нормально разомкнутая

**Схема подключения:**

-	*Дисплей OLED:* SDA -> D5, SCL -> D6, VCC -> 3V3, GND -> GND
-	*Датчик влажности:* VCC -> D3, GND -> GND, A0 -> A0 (Для снижения коррозии датчика питание на него подаётся только в момент измерения)
-	*Датчик уровня:* Контакт 1 -> D2, Контакт 2 -> GND
-	*Кнопка:* Контакт 1 -> D8, Контакт 2 -> 3V3
-	*MOSFET:* Signal PWM+ -> D7, Signal PWM- -> GND, DC+ -> VU, DC- -> GND, Controlled device -> Помпа (Для уменьшения паразитных наводок между контактами помпы катодом (полоской на корпусе) к плюсу подключён диод 1N4007)

Устройство предназначено для поддержания влажности почвы в горшке с растением выше порогового значения. Для измерения влажности почвы используется резистивный датчик, требующий калибровки. Калибровка проводится с помощью тестового скетча, следует записать максимальное значение (датчик находится в воздухе) и минимальное значение (датчик полностью погружён в воду). Эти значения следует внести в файл ****.h

Полив осуществляется циклически: сначала производится измерение влажности; если она ниже пороговой - на заданное время полива включается помпа и, по истечении заданного времени впитывания, происходит переход к началу цикла; если она выше пороговой - включается режим  паузы, по завершении которой происходит переход к началу цикла. Если с датчика влажности приходят нулевые данные (обрыв провода) или после трёх поливов подряд значение влажности не изменилось, цикл прерывается и выдаётся сигнал ошибки датчика. После устранения проблемы с датчиком необходимо перезагрузить устройство.

Помпа размещена в резервуаре с водой, уровень которой контролируется поплавковым датчиком. При срабатывании датчика цикл прерывается и выдаётся сигнал об отсутствии воды. При доливе воды в резервуар полив автоматически возобновляется.

При нажатии кнопки цикл полива запускается принудительно.

Параметры полива задаются пользователем, их значения при включении устройства:

- Пороговая влажность = 10% (регулируемая от 10 до 80%)
- Время полива = 3 секунды (регулируемое от 1 до 10 секунд)
- Время впитывания = 30 секунд (регулируемое от 10 до 90 секунд)
-	Пауза = 1 минута (регулируемая от 1 до 120 минут)

Значения параметров полива сильно зависят от размеров горшка и расстояния между датчиком влажности и местом, куда поступает вода из резервуара. Эти значения следует подбирать экспериментально. Также нужно учитывать рекомендуемые для поливаемого растения значения влажности почвы.

Через Wi-Fi и MQTT устройство подключается к Home Assistant (HA), который позволяет задавать параметры полива, отображать телеметрию, запускать принудительный полив. С помощью HA сообщения об ошибках также высылаются в виде push-уведомлений на устройство с установленным приложением HA. Идентификация устройства в HA производится автоматически на базе MAC-адреса, что позволяет бесконфликтно подключать несколько УГ.

На дисплей устройства выводятся:
-	Статус Wi-Fi (Подключение/Подключено/Ошибка)
-	Статус HA (Подключение/Подключено/Ошибка)
-	Пороговая влажность
-	Текущая (последняя измеренная) влажность 
-	Состояние УГ (Полив/Впитывание/Пауза/Ошибка)
-	Время в секундах до окончания текущего Состояния УГ или сообщение с Типом ошибки, если она появилась
